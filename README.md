# OIBSIP Internship Projects

This repository contains the projects completed during my Oasis Infobyte internship.

## Completed Tasks

### Task 2 - BMI Calculator

A Python-based BMI Calculator that calculates Body Mass Index based on the user's height and weight.

**Technology:** Python

### Task 3 - Password Generator

A Python-based Password Generator that creates secure random passwords based on user requirements.

**Technology:** Python

### Task 4 - Weather App

A Python-based Weather Application that retrieves current weather information for a selected city using a weather API.

**Features:**
- Temperature in Celsius
- Temperature in Fahrenheit
- Humidity
- Weather condition
- Wind speed
- City-based weather search

**Technology:** Python, Requests, python-dotenv

### Task 5 - Chat Application

A client-server based chat application that allows communication between a client and server using Python socket programming.

**Technology:** Python, Socket Programming
