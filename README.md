## ▶️ How to Run

### Task 2 – BMI Calculator

```bash
cd Task2_BMI_Calculator
python3 bmi_calculator.py
```

### Task 3 – Password Generator

```bash
cd Task3_Password_Generator
python3 password_generator.py
```

### Task 4 – Weather App

```bash
cd Task4_Weather_App
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 weather_app.py
```

> For Weather App environment variables and API configuration, refer to the task-specific README.

### Task 5 – Chat Application

Open two terminals.

**Terminal 1 – Server:**

```bash
cd Task5_Chat_Application
python3 server.py
```

**Terminal 2 – Client:**

```bash
cd Task5_Chat_Application
python3 client.py
```
