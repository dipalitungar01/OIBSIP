# Weather App

A Python-based Weather App that fetches real-time weather information for a city using a weather API.

## Features

- Enter any city name
- Get current temperature in Celsius
- Get temperature in Fahrenheit
- Display humidity
- Display weather condition
- Display wind speed
- Uses `.env` file to securely store the API key

## Technologies Used

- Python
- Weather API
- python-dotenv
- Requests
